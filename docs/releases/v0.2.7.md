# RootWalk v0.2.7

v0.2.7 improves source-backed occurrence-time investigation while preserving the
evidence and benchmark-integrity boundaries introduced in earlier releases.

## Highlights

- Adds auditable business-impact and trace-operation evidence profiles.
- Prioritizes strong, sufficiently sampled onset evidence over earlier weak spikes.
- Separates occurrence-only recommendations from formal Finding gates without
  weakening Finding evidence requirements.
- Keeps model ownership of hypothesis and occurrence selection; Runtime validates
  schema, scope, evidence references, budgets, and exit safety.
- Exports proof-bound public fault types instead of internal explanatory prose.
- Adds overlap-aware occurrence evidence grouping and regression coverage.

## Evaluation snapshot

The frozen Ark development run on a fixed 12-case OpenRCA Telecom slice scored
8/12 strict and 8.5/12 partial. The slice was used during development and is not an
unseen benchmark result. Real telemetry, evaluation labels, model credentials, and
RunBundles are intentionally excluded from this repository.

## Security and data boundary

Model credentials are read only from environment variables. OpenRCA telemetry and
evaluator-only labels must stay outside the Git worktree. See
[security.md](../security.md) for the complete boundary.
