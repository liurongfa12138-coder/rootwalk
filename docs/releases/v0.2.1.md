# RootWalk v0.2.1

RootWalk v0.2.1 adds an audited Recommendation terminal outcome for the dynamic
Frontier. The strict Finding contract from v0.2.0 is unchanged.

## Finding, Recommendation, and Abstention

- A Finding still requires complete material-anomaly coverage, a selected supported
  hypothesis, a root-cause disposition, no open questions, and mechanism-eligible
  typed Evidence.
- A Recommendation is emitted only after an explicit Abstention when one current-best
  hypothesis has model-authored `supports` EvidenceAssessment state for a non-boundary,
  fault-type-ready typed profile with a mechanism signature.
- A Recommendation is rejected when the hypothesis has a latest `refutes` assessment,
  another subject has an equal or stronger typed-ready profile, the selected Evidence
  is absent, or the unresolved anomaly audit differs from the persisted registry.
- The RunBundle records `frontier-supported-v1`, the exact supporting Evidence,
  public fault type, mechanism signature/rank, root-cause score, unresolved anomaly
  IDs, and one audit event. The OpenRCA exporter reconstructs and verifies all of
  these fields before emitting a low-confidence fallback prediction.
- Pure Abstention remains the outcome when no hypothesis satisfies that contract.

## Evaluation

The p26 evaluation replays the same 12 frozen v0.2.0 model decisions and tool
observations. It changes only terminal Recommendation generation and export, so the
comparison is not affected by model sampling.

- v0.2.0: `2/12` official strict, `3.17/12` official partial.
- v0.2.1 p26 replay: `3/12` official strict, `4.17/12` official partial.
- The increment is row 33. Formal Finding remains withheld with three unresolved
  material anomalies; the audited Recommendation exports `db_007 / db close` from an
  `availability_state_transition` typed profile.

This score remains a benchmark snapshot, not a claim that Telecom RCA accuracy is
solved. v0.2.1 preserves the distinction between formal Findings and lower-confidence
Recommendations in every RunBundle.
