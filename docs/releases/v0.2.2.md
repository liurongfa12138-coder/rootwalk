# RootWalk v0.2.2

RootWalk v0.2.2 stabilizes dynamic Frontier investigation without weakening the
evidence contract. OpenRCA remains an Adapter and a frozen evaluation suite; the
Harness Core contains no row IDs, benchmark labels, component-specific answers, or
evaluator-shaped branches.

## Dynamic investigation contracts

- `advance_frontier` commits model-authored Reflection state and recompiles Context
  without manufacturing a Tool Observation. It can advance only after every anomaly
  on the active page has a resolved, Evidence-backed disposition.
- A page certificate lists missing anomaly-disposition slots. Valid partial slots are
  persisted even when the page cannot advance, so one omitted slot no longer discards
  the rest of a model-authored Reflection.
- Material anomalies use leader-aware pagination: unprofiled events are prioritized
  while no typed-ready leader exists; after a leader appears, the active page favors
  disposition and causal proof instead of continuing an exhaustive scan.
- Challenger discovery is paginated in bounded pages of at most eight unprofiled
  candidates. It stops when a typed-ready leader exists or physical closeout begins.
- Current-best ownership is explicit. Omitted or null `current_best_hypothesis_id`
  retains the existing leader; `clear_current_best=true` is required to clear it.
- Hypothesis-creation, leader-selection, and Recommendation certificates expose the
  exact structured slots the model must fill. Runtime validates them but never derives
  a Hypothesis, Evidence polarity, or anomaly disposition from prose.
- A current-best leader must have direct support from a same-subject, typed,
  fault-ready, non-boundary mechanism profile when such Evidence exists. Excluding
  rival candidates cannot substitute for root-cause support.

## Reliability and auditability

- Frontier Context compacts profile arguments, anomaly registry entries, Evidence
  polarity indexes, and validation feedback. Required Context remains under the
  fixed 21,000-token limit without increasing that limit.
- Provider timeouts retry while physical budget remains. At physical closeout Runtime
  emits an audited Abstention, preserves unresolved anomalies, and never synthesizes a
  model conclusion.
- Formal Findings require a non-boundary mechanism signature and complete material
  anomaly coverage. Generic pressure can remain a Recommendation or Abstention but
  cannot become a Finding merely because the budget expires.
- Physical closeout prohibits new exploratory queries, not a Finding already grounded
  in complete visible Evidence. Stale open questions must be cleared through a
  closeout Reflection.
- The OpenRCA exporter independently verifies Recommendation polarity, typed gate,
  mechanism rank, competing peers, unresolved anomaly audit, and policy provenance.
  A Recommendation with zero unresolved material anomalies is rejected.

## Frozen evaluation

The release candidate is `m101 / openrca-public-input-v71 / terminal p40 /
frontier-reflection-v33`. The 12 Telecom cases were run once as one frozen version
with four-way concurrency; Market unseen was run alongside them. Labels were available
only to the isolated evaluator.

- v0.2.1 frozen baseline: `3/12` official strict, `4.17/12` official partial.
- v0.2.2: `4/12` official strict, `5.17/12` official partial.
- All 12 Telecom runs reached `completed_partial`; there were no runtime failures,
  context-limit exits, or budget-exhausted exits.
- Market unseen reached an audited Abstention with no formal Finding, preserving the
  generic-pressure safety gate.
- Strict-correct rows were 11, 32, 33, and 35. Row 15 scored `0.67` and row 31 scored
  `0.5`. These row IDs are evaluation reporting only and are not referenced by Core
  code or Runtime policy.

This is a benchmark snapshot, not a claim that Telecom RCA is solved. The same release
still Abstains when public telemetry does not provide mechanism-ready Evidence.

## Known limits

- Several Telecom network and database events are material but not fault-type-ready
  under the current Adapter Extractor. Dynamic pagination can ensure those profiles
  are checked, but the Harness correctly refuses to infer a mechanism they do not
  prove.
- Time-only RCA outputs still share the full causal investigation contract. A future
  generic output-dimension policy should allow onset-only conclusions without
  weakening component-and-reason Findings.
- Provider latency remains the dominant wall-clock cost. Logical Frontier depth is not
  capped early, while wall-clock, provider timeout, Tool, Artifact, and sandbox
  boundaries remain physical safety limits.
